# JSON&gt;CSV

A private, browser-only JSON to CSV converter. Paste JSON or import a `.json` file, inspect the flattened table, then copy or download the CSV.

## Use

Open [index.html](index.html) in a browser. No installation, server, or data upload is required.

Supported input includes arrays of objects, a single object, and objects containing an array of records. Nested object keys become dot-separated CSV columns.
